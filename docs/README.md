# MGQ Admin — Docs

Este directorio es el “libro” operativo del proyecto. Objetivos:

- Reducir suposiciones y cambios involuntarios de UI/DB.
- Centralizar definiciones: entidades, tablas/columnas, reglas de negocio y convenciones de UI.
- Permitir trabajo diario incremental: al final del día se actualiza este directorio.

## Reglas de trabajo

1. Antes de proponer cambios, referenciar el documento relevante de `/docs`.
2. Si falta información, primero se agrega al documento correspondiente y recién después se cambia código.
3. Convenciones de UI (tablas, campos visibles, etc.) se consideran “contrato” hasta que se documente un cambio.
